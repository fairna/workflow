# Rumah123 Brand Guidelines

## Purpose

This file defines the brand identity references and the non-negotiable rules for using Rumah123 brand assets in carousel designs.

## Task

### Canvas and Export

- Default canvas: portrait 4:5.
- Reference resolution: 1080 × 1350 px.
- Export each slide as an individual PNG.
- Preserve the 4:5 ratio unless the user requests a different format.
- Keep critical text and visual elements inside a safe area.
- Avoid placing critical content at extreme edges or where Instagram interface elements may obscure it.

### Logo Integrity

- Use the original Rumah123 logo asset when available.
- Never stretch, distort, redraw inaccurately, or arbitrarily recolor the logo.
- Maintain sufficient contrast between the logo and its background.
- Use a clearly labeled placeholder if the actual logo asset is unavailable.
- Do not claim a placeholder is the official logo.

### Readability

- Maintain sufficient contrast between text and background.
- Ensure typography remains readable on a mobile screen.
- Do not place important text over visually busy imagery without a suitable overlay or panel.

## Soft Guidelines

### Logo Placement

- Top-left placement is a preferred reference, not an absolute layout requirement.
- White logo generally works on dark backgrounds.
- Blue logo generally works on light backgrounds.
- A width of approximately 150–190 px may be used as a starting reference on a 1080 px canvas.
- Keep logo scale and treatment coherent across slides in the same carousel.

### Estimated Color Palette

| Name | Hex | Suggested Role |
|---|---|---|
| Navy | `#0B1B3F` | Dark editorial background and emphasis |
| Cobalt | `#2850A8` | Primary brand color, backgrounds, text, graphic elements |
| Off-white | `#F3F6FA` | Light background and negative space |
| Amber | `#FFC233` | Accent and selected highlights |
| White | `#FFFFFF` | Text, logo, and contrast elements |
| Tile gray-blue | `#DCE4F0` | Supporting panels and tiles |
| Tile border | `#9FB1D0` | Supporting borders |
| Dark text on amber | `#0B1B3F` | Text placed on amber |

### Color Application

- Use the palette as the primary visual reference.
- Select background colors according to the story and composition.
- Amber is generally more effective as an accent than as a dominant background.
- Avoid unnecessary colors that compete with the brand palette.
- Secondary text may use a lighter tint of the foreground color.
- Decorative elements should remain subordinate to the main content.

Do not enforce a fixed sequence such as navy cover → off-white answer → cobalt data slide.

### Typography

| Role | Font Direction | Examples |
|---|---|---|
| Editorial headline | Serif | Cormorant Garamond, Playfair Display, Georgia |
| Body and supporting text | Sans-serif | Inter, Plus Jakarta Sans, system sans-serif |

Suggested sizes for a 1080 × 1350 px canvas:

| Element | Reference Size |
|---|---:|
| Main headline | 96–120 px |
| Subheading | 40–48 px |
| Body copy | 30–36 px |
| Key figure | 56–72 px |
| Caption and units | 24–28 px |

These values are starting points, not fixed limits. Adjust size, weight, line spacing, and alignment to fit the composition and preserve hierarchy.

### Signature Highlight

A rounded amber rectangle with dark navy text may be used to emphasize a key word or short phrase.

- Use selectively.
- Avoid highlighting multiple competing elements.
- Keep punctuation outside the highlight when appropriate.
- Do not force this treatment into every slide.
